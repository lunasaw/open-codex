# 重构验收范围

本轮聚焦通用 Host 与业务解耦：仅 v2 配置、无业务平台包依赖、可选 Python Provider、可配置 Skill 根、原生 MCP，以及通用前端观察和恢复。

2026-10-16 本轮验证结果：

- 在仅安装 Host 依赖的隔离 Python 环境中，151 项测试全部通过，包含真实 Codex 0.154.0 与本地模拟模型/MCP。
- 外置 Skill 加载、独立 MCP 发现/调用/审批/结果消费、配置加载 Python Tool 及重启恢复均通过真实原生协议验证。
- 前端 15 项单测、类型检查与构建通过；通用对话、原生工作台、会话交互三组浏览器回归全部通过。
- 独立 wheel 安装、无 Galatea distribution/业务模块、静态页面打包检查通过。
- systemd 渲染结果和模板通过语法验证；验证时仅在临时文件中替换不存在的部署 executable，未安装或启动 unit。

历史协议测试要求运行包的文件内容和执行位同时匹配冻结样本。本地 NPM 安装目录受 umask 影响，执行位与样本不同；本轮使用临时副本恢复样本执行位并逐文件验证摘要，未修改现有 runtime、样本或运行服务。可复现命令见 [测试验收](09-test-acceptance.md)。

旧版本的训练工具、业务预检和发布接纳结论不适用于新 Host。实际平台训练与第二阶段业务可视化未纳入此轮交付。
