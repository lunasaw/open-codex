# 两阶段实施边界

第一阶段交付通用执行能力：原生 Codex Agent Loop、可配置 Skill 根、原生 MCP、通用 Python Tool Provider、权限/审批、幂等日志和恢复，以及现有通用网页。

本次删除固定 Galatea 工具、内置业务 Service 装配、项目/实验授权字段、训练平台预检和业务依赖，不保留旧配置分支。

第二阶段再定义业务接入协议：外部 MCP/Provider 提供资源查询、上传、计划、训练提交、任务观察和回执；Skill 定义业务规则与自定义节点；Agent 自主判断步骤和所需工具。页面随后消费明确的业务事件，展示阶段、预算、文件和产物。

阶段图只是 Agent 已判断和已观察结果的业务投影。不能从界面当前节点推断任务已完成，也不以固定前端流程限制 Agent 的回退、补充信息与重试。
