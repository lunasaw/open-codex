# 通用网页工作台

当前网页提供对话、原生模型和权限设置、Skills、MCP、插件、文件、终端、审批、用户问题、会话分叉/压缩/恢复以及通用执行记录。

界面参照同工作区 `codex-webui` 的桌面布局：46px 顶栏、可折叠的项目会话分组、居中对话与输入区、右侧任务面板和底部终端。
主题覆盖浅色与深色；手机上的任务面板使用全屏对话框，支持 Escape 关闭和焦点约束。

- 顶栏的“更改”按轮次显示已观察到的文件补丁，支持自动换行、折叠文件和打开文件预览。
  同一文件的多次修改按观察顺序展示，行数是这些补丁的累计值，不代表工作树的最终净差异。
  面板当前只读，不提供 Undo/Reapply；观察历史未完整加载时会显示提示。
- “文件”调用原生 `fs/readDirectory`，支持目录切换和原有文件预览。完整编辑功能仍在设置中。
- “摘要”展示当前环境、最新结构化计划和原生 Token 使用量；缺失数据使用空状态。
- 底部终端复用 `command/exec` 及其输入、输出、终止接口，关闭面板后保留输入和输出。
  这是命令执行面板，尚不是 xterm.js/PTY 交互式终端。

布局组件和样式位于 `frontend/src/workbench.tsx`、`workbench.css`，Diff 数据选择位于
`workbench-data.ts`。Host、原生权限和审批机制继续独立于界面布局。

Console 只投影原生消息、工具参数/结果和观察状态，不把工具返回值中的 job、dataset 或 experiment 字段解释为业务实体。业务阶段与产物可视化留在第二阶段。

观察格式为 `codex-agent.console/v1`，事件格式为 `codex-agent.console.event/v1`。`memory/process_lifetime` 和 `sqlite/persistent` 是当前可选存储后端；SQLite 数据库存放在 `state_dir/console.sqlite3`。

SSE 游标、分页和回放描述已观察信息，不推断未观察任务已完成。完整原生结果保留在通用 Tool 展示中，密钥和私有推理不公开。

浏览器每 5 分钟自动更新事件连接；45 秒未收到任何数据（包括心跳）时自动重试，
切回页面、恢复网络或从页面缓存返回时立即恢复连接。重连沿用最后处理的游标补回事件，
保留输入草稿、已加载的聊天和阅读位置。该机制仅维护浏览器与 Host 的连接，不发送聊天消息。

工作台面向受控环境中的单一 Host 身份。正式对外开放需在网络入口增加认证、授权和隔离。

项目与会话管理：项目以独立 ID 保存，多个项目可指向同一目录；侧栏支持创建、重命名、拖动排序和移除。
移除项目只删除当前浏览器的项目组织信息，保留目录、文件和会话；该项目的会话移至“其他会话”，
刷新后不会自动重建已移除项目，也不会并入同目录的另一项目。项目组织目前保存在浏览器 localStorage，不跨设备同步。

会话菜单提供原生归档、取消归档、删除、分叉、回退上一轮和任意轮回退；用户消息和助手答复旁可从指定轮分叉或回退。
归档记录在“恢复会话 → 已归档”中管理。分叉包含指定轮及之前的历史，工作目录文件仍共享；
回退移除所选轮及后续对话，不撤销文件修改。0.163.0 已移除 thread/rollback；分页会话通过 thread/revert 回退，legacy 会话保留继续对话和分叉能力，原地回退会明确提示不支持。
删除调用 thread/delete，并保留原生限制：分页历史仍被分叉引用时拒绝删除；运行中的会话需先停止。
归档成功后清除该会话的 Console 事件和消息/步骤投影，仅保留 Codex 原生归档历史；取消归档时从原生历史重建界面。
删除成功后，原生 `thread/delete` 清除原生历史，Host 同时清除对应 Console 记录，不备份 JSONL。
SQLite 清理包含 WAL 检查点和空间回收；其他会话的事件编号与游标保持不变。迟到的事件不会重新写入已归档或删除的会话。
启动时也会清理 Host 已标记归档/删除的旧会话记录。仅保存不含消息内容的清理标记，防止重启后重新写入。
Host 的请求幂等凭据、工具执行凭据和删除标记独立于 Console SQLite，继续保留以避免重复执行；项目文件不受会话删除影响。
这些行为通过 tests/test_thread_lifecycle.py（真实固定版 Codex + 本地合成模型）和
 tests/test_thread_lifecycle.cjs（浏览器交互）验证；不表示覆盖 Codex Desktop 的全部功能。

## 设置与会话操作的作用范围（2026-10-18）

全局设置只管理账户、浏览器偏好、用户/项目默认配置和共享服务。`/` 管理当前聊天，
会话弹层显示聊天名称，切换聊天时关闭。弹层沿用“配置”页的标签、说明、控件和分隔行布局。

| 设置项 | 全局保留 | 会话入口 |
| --- | --- | --- |
| 配置 | 用户/项目配置、103 个原生配置域、新聊天默认值 | `/settings` 修改当前聊天或本轮模型与权限；`/advanced` 完整原生运行参数 |
| 模型与权限 | 改为“模型与实验功能”：服务商能力、联网搜索默认值、实验开关 | `/model`、`/reasoning`、`/permissions`、`/settings` |
| 账户与登录 | 登录、认证、账户额度与相关操作 | 无 |
| 使用情况和计费 | 账户额度、重置时间、账单；API Key 不调用 ChatGPT 额度接口 | `/status` 查看聊天 ID、当前上下文、累计 Token、账户速率限制 |
| 聊天资源 | 移出设置 | `/resources`：持久附件、阅读状态、预测与聊天 Shell |
| 高级原生能力 | 插件共享对象、实例存储维护 | `/advanced`：创建/恢复/分叉、聊天/轮次设置、启动/引导轮次和审查 |
| Skills | 启用/停用、额外目录、发现配置 | `/skills`：选择并发送 Skill 输入 |
| MCP | 服务配置、授权、全局重载、状态 | `/mcp`：聊天范围的状态、工具调用、资源读取与订阅 |
| Apps | 目录、安装状态、账户连接 | `/apps`：聊天可用 Apps 和交互应用；没有聊天时仍可按需创建应用会话 |
| 插件 | 安装/卸载、市场、同步、共享 | `/plugins`：当前聊天禁用的插件列表 |
| Memory | 共享记忆状态、默认配置、重置所有记忆 | `/memory`：此聊天记忆模式 |
| Hooks | 工作目录的 Hooks 配置、信任与共享默认值 | `/hooks`：当前聊天的执行记录 |
| 语音 | 浏览器音色、设备、版本和传输偏好 | `/voice`：初始上下文、指令、Handoff；按 thread ID 存入 sessionStorage，不跨聊天复用 |
| 诊断与反馈 | 实例诊断、不关联聊天的反馈 | `/feedback`：明确关联当前聊天的反馈 |
| 执行流程、原生事件 | 移出设置 | `/loop`、`/native`；保留聊天菜单入口 |
| 终端 | 从设置导航移除 | 底部终端；`/background` 管理当前聊天的后台命令 |
| 远程控制、执行环境、导入、Windows sandbox | 实例连接、环境目录、迁移和主机就绪配置 | 现有创建聊天/环境选择流程 |
| 能力、帮助、开发者工具 | 实例能力、命令说明、手动协议调试；调试参数不再自动填入当前聊天 | `/help`；`/agents`、`/approvals` 打开会话任务面板 |

`/` 按钮旁的进度圈 = 最新原生 `last.totalTokens / modelContextWindow`，不是累计账单 Token，
也不是压缩任务进度。点击进度圈或选择 `/status` 查看绝对用量、容量和剩余百分比。
80% 起提示占用较高，95% 起提示接近容量；这只是界面提醒，不承诺原生自动压缩阈值，
也不会自动触发压缩。缺少用量/容量时显示“待更新”，压缩后随原生用量事件刷新。
