# 原生工作台能力

网页提供新建/恢复/搜索会话、模型与推理强度、计划模式、权限、Skill、MCP、插件、文件、终端、图片输入、压缩、分叉、审查、上下文回退、归档和运行中补充指令。

会话中的文件链接和工具读取记录可直接在右侧打开，支持多标签阅读、行号范围定位、
Markdown 预览与源码切换。目录、diff 和会话使用同一文件入口；手机和平板以全屏面板阅读。
文件阅读与 diff 保持预览模式；右侧文件管理入口提供文本编辑、复制、删除与变化监听。
底部终端采用 xterm，支持 PTY、输入、调整大小、停止及刷新恢复。
具体功能分布与验收范围见 [Web 能力对齐](17-web-capability-parity.md)。

审批、权限申请、用户问题和 MCP 表单显示在所属消息流；其他线程的请求保持独立身份。用户响应通过原生协议发送，页面不自动批准。上下文回退不会撤销磁盘文件修改。

固定 0.163.0 协议中，初始化由 Host 管理，其余方法通过原生桥和 JSON Schema 校验可达。常用功能提供表单，其余可用开发者工具；可达不代表账号、功能开关或服务可用。

目标、队列、Apps、远程插件、实时音频已有专用交互。外部服务与平台条件仍由原生运行时判断；
账号页面按用户要求排除。外部 ChatGPT token 刷新和 attestation 没有可用的客户端提供方，Host 返回明确不支持，
不伪造凭据、不转成用户手填 JSON。不能用合成浏览器测试替代外部服务的真实环境验收。

默认线程权限是 workspace-write/on-request，可在网页显式选择其他模式。Host 自定义工具 actions 与原生文件/MCP 权限分别验证。训练业务约束由后续业务服务和 Skill 接入。

默认源码配置使用 SQLite 保存经过脱敏的观察历史；memory 后端也可显式选择。旧配置/旧状态不在本次重构中自动迁移。
